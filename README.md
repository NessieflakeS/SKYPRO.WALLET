## 📖 О проекте

SkyproWallet - это современное веб-приложение для управления личными финансами, позволяющее:
- 📊 **Отслеживать расходы** по категориям
- 📈 **Анализировать финансовые привычки** с помощью диаграмм
- 📱 **Работать на любом устройстве** благодаря адаптивному дизайну
- 🔐 **Безопасно хранить данные** с системой аутентификации

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 16+ 
- npm или yarn

### Установка и запуск

```bash
# Клонирование репозитория
git clone <url-репозитория>
cd skypro-wallet

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build

# Запуск тестов
npm test
Приложение будет доступно по адресу: http://localhost:3000

🛠 Технологии
Frontend: React 19.2.0, React Router DOM 7.9.6

State Management: React Context API + useReducer

Стили: CSS3 с Flexbox/Grid, адаптивный дизайн

Валидация: Кастомные валидаторы для форм

Хранение данных: Local Storage браузера

Тестирование: Jest, React Testing Library

Code Quality: ESLint, Prettier
